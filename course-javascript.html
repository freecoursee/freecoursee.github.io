جافاسكربت للمبتدئين

جافاسكربت هي اللغة الوحيدة التي تعمل داخل المتصفح مباشرة، وهي ما يحوّل الصفحة الجامدة إلى تطبيق تفاعلي. ستتعلم هنا الأساس الذي تبني عليه أي إطار لاحقاً.

1المتغيرات وأنواع البيانات

تُعلَّن المتغيرات بالكلمتين let وconst. استخدم const افتراضياً للقيم التي لا يُعاد إسنادها، واستخدم let عندما تعرف أن القيمة ستتغير. تجنّب var القديمة لأن سلوكها يسبب أخطاء مربكة.

const name = "علي";
let score = 0;
score = score + 10;
console.log(name, score);

الأنواع الأساسية: string للنص، number للأرقام (صحيحة وعشرية معاً)، boolean للقيمتين true وfalse، إضافة إلى array للقوائم وobject للكائنات التي تجمع خصائص:

const colors = ["أحمر", "أخضر"];
const user = { name: "علي", age: 20 };
console.log(user.name, colors[0]);

لترى النتائج افتح المتصفح واضغط F12 ثم تبويب Console، وكل ما تكتبه بـ console.log سيظهر هناك. هذه أسهل طريقة لتجريب الكود وفهم ما يحدث.

2الشروط والحلقات

جملة if تنفذ كوداً إذا تحقق الشرط:

const hour = 14;
if (hour < 12) {
  console.log("صباح الخير");
} else if (hour < 18) {
  console.log("مساء الخير");
} else {
  console.log("طاب مساؤك");
}

انتبه إلى الفرق بين == و ===: الأولى تحاول تحويل الأنواع قبل المقارنة فتعطي نتائج غريبة مثل 0 == "" صحيحة، أما الثانية فتقارن القيمة والنوع معاً. اعتمد === دائماً.

الحلقة for مناسبة عندما تعرف عدد التكرارات، وwhile عندما تعتمد على شرط:

for (let i = 1; i <= 3; i++) {
  console.log("رقم", i);
}

القيم التي تُعتبر خاطئة عند الفحص (falsy) هي: false و 0 و "" و null و undefined و NaN، وما عداها يُعتبر صحيحاً. معرفة هذه القائمة توفر عليك ساعات من البحث عن أخطاء الشروط.

3الدوال والمصفوفات

الدالة تغلّف كوداً قابلاً لإعادة الاستخدام. يمكن كتابتها بالطريقة التقليدية أو بالدالة السهمية الأقصر:

function add(a, b) {
  return a + b;
}
const double = (n) => n * 2;
console.log(add(2, 3), double(4));

للمصفوفات دوال جاهزة مفيدة جداً: push تضيف عنصراً للنهاية، وpop تحذف الأخير، وlength تعطي العدد. وأهمها ثلاث دوال تعمل على كل العناصر:

const nums = [1, 2, 3, 4];
const doubled = nums.map(n => n * 2);      // [2,4,6,8]
const even = nums.filter(n => n % 2 === 0); // [2,4]
const total = nums.reduce((s, n) => s + n, 0); // 10

map تُرجع مصفوفة جديدة بعد تحويل كل عنصر، وfilter تُرجع العناصر التي تحقق شرطاً، وreduce تجمع كل العناصر في قيمة واحدة. إتقان هذه الثلاثة يغنيك عن كثير من الحلقات الطويلة.

4التعامل مع الصفحة (DOM)

الـ DOM هو تمثيل صفحة HTML ككائنات يمكن لجافاسكربت قراءتها وتعديلها. نحدد العنصر بـ querySelector باستخدام محدد CSS نفسه:

<button id="btn">اضغط</button>
<p id="msg"></p>

<script>
  const btn = document.querySelector("#btn");
  const msg = document.querySelector("#msg");
  btn.addEventListener("click", () => {
    msg.textContent = "تم الضغط!";
  });
</script>

الدالة addEventListener تربط حدثاً (مثل click أو input أو submit) بدالة تُنفَّذ عند حدوثه. وللتعديل: textContent يغيّر النص، وclassList.add يضيف صنفاً CSS، وstyle يغيّر التنسيق مباشرة.

ضع وسم script في آخر الصفحة قبل إغلاق body، لأن الكود يحتاج أن تكون العناصر قد حُمّلت قبل البحث عنها. وهذه الأفكار الثلاثة (اختيار عنصر، الاستماع لحدث، تعديل العنصر) هي أساس معظم التفاعل الذي تراه في المواقع.
