بايثون من الصفر للمبتدئين

بايثون من أسهل لغات البرمجة قراءةً، وتُستخدم في تحليل البيانات وبناء المواقع والأتمتة. في هذا الكورس ستكتب برامج صغيرة حقيقية من أول درس.

1التثبيت وأول برنامج

حمّل بايثون من الموقع الرسمي python.org وثبّته، ومن المهم أن تفعّل خيار Add Python to PATH أثناء التثبيت حتى يعمل الأمر من سطر الأوامر. بعد التثبيت افتح محرراً مثل VS Code أو حتى Notepad، واكتب البرنامج الأول:

print("مرحباً بالعالم")

احفظ الملف باسم hello.py ثم شغّله من سطر الأوامر بالأمر python hello.py. الدالة print تعرض ما بداخل القوسين على الشاشة، وهي أكثر دالة ستستخدمها وأنت تتعلم لأنها تريك ماذا يحدث داخل برنامجك.

التعليقات سطور يتجاهلها بايثون وتُكتب لتوضيح الكود للقارئ، وتبدأ بعلامة #:

# هذا تعليق ولن يُنفَّذ
print(2 + 3)  # الناتج 5

نصيحة عملية: لا تنسخ الأمثلة فقط، بل غيّر القيم وشاهد ماذا يحدث. الخطأ في هذه المرحلة جزء طبيعي من التعلم، ورسالة الخطأ في بايثون تخبرك عادةً برقم السطر ونوع المشكلة.

2المتغيرات وأنواع البيانات

المتغير اسم يشير إلى قيمة محفوظة في الذاكرة. تنشئه بالإسناد مباشرة دون كلمة خاصة:

name = "علي"
age = 20
price = 9.99
is_student = True

الأنواع الأربعة الأساسية هي: int للأعداد الصحيحة، وfloat للأعداد العشرية، وstr للنصوص، وbool للقيمتين True وFalse. تعرف نوع أي قيمة بالدالة type().

لقراءة مدخلات من المستخدم استخدم input، وتذكّر أنها تُرجع نصاً دائماً، فإذا أردت رقماً حوّله بـ int():

x = int(input("اكتب رقماً: "))
print(f"ضعف الرقم هو {x * 2}")

الصيغة f"..." تسمح بوضع المتغيرات داخل النص بين أقواس معقوصة، وهي أنظف من جمع النصوص بعلامة +. أسماء المتغيرات حساسة لحالة الأحرف، فـ Age تختلف عن age، والأفضل استخدام أسماء واضحة مثل total_price بدل حرف واحد.

3الشروط والحلقات

الشروط تجعل البرنامج يتخذ قراراً. في بايثون يحدد الإزاحة (المسافة البادئة) أين تبدأ الكتلة وأين تنتهي، لذلك انتبه لها:

score = 75
if score >= 90:
    print("ممتاز")
elif score >= 60:
    print("ناجح")
else:
    print("حاول مرة أخرى")

عوامل المقارنة هي == و != و < و > و <= و >=، ويمكن الجمع بينها بالكلمات and و or و not.

الحلقة for تكرر الكود على عناصر متتابعة، والدالة range تولّد الأرقام: range(3) تعطي 0 ثم 1 ثم 2 (تبدأ من الصفر وتتوقف قبل الرقم الأخير).

for i in range(1, 4):
    print("الجولة", i)

n = 3
while n > 0:
    print(n)
    n -= 1

الحلقة while تستمر ما دام الشرط صحيحاً، فاحرص أن يتغير شيء داخلها ليصبح الشرط خاطئاً في وقت ما، وإلا ستدور للأبد.

4الدوال والقوائم

الدالة مجموعة أوامر تعطيها اسماً لتستدعيها متى شئت بدل تكرار الكود. تُعرَّف بالكلمة def وتُرجع نتيجة بـ return:

def area(width, height):
    return width * height

print(area(4, 5))   # 20

القائمة (list) تحفظ عدة قيم بترتيب، وتُكتب بين أقواس مربعة، ويبدأ ترقيم عناصرها من صفر:

fruits = ["تفاح", "موز"]
fruits.append("برتقال")
print(fruits[0])      # تفاح
print(len(fruits))    # 3
for f in fruits:
    print(f)

أما القاموس (dict) فيربط مفتاحاً بقيمة، مثل {"name": "علي", "age": 20}، وتصل للقيمة بمفتاحها: person["name"].

بعد هذه الدروس أنت قادر على كتابة برامج مثل: حاسبة بسيطة، أو لعبة تخمين رقم، أو برنامج يحسب معدل درجات. أفضل طريقة للتقدم أن تختار مشروعاً صغيراً وتبنيه خطوة خطوة.
