CSS: تصميم صفحات جميلة ومتجاوبة

إذا كانت HTML هي الهيكل فـ CSS هي الشكل: الألوان والخطوط والمسافات والتخطيط. ستتعلم الأساسيات التي تحتاجها لبناء صفحة مرتبة تعمل على الجوال والحاسوب.

1كيف تعمل CSS

قاعدة CSS تتكون من محدد (يختار العناصر) وخصائص (تصف الشكل):

p {
  color: #333;
  font-size: 18px;
}

أفضل طريقة لإضافتها ملف خارجي تربطه في head:

<link rel="stylesheet" href="style.css">

أنواع المحددات الأساسية: محدد الوسم (p)، ومحدد الصنف ويبدأ بنقطة (.card)، ومحدد المعرّف ويبدأ بعلامة # (#header). الأصناف قابلة للتكرار على أي عدد من العناصر فهي الأكثر استخداماً، أما المعرّف فيجب أن يكون فريداً في الصفحة.

عند تعارض قاعدتين يفوز الأكثر تحديداً، ثم الأحدث في الترتيب. فلو ضبطت لوناً بالصنف ولوناً بالوسم، يفوز الصنف. ويمكنك تعريف متغيرات للألوان لتغيير الموقع كله من مكان واحد:

:root { --main: #0f766e; }
a { color: var(--main); }

2نموذج الصندوق

كل عنصر في الصفحة صندوق مكوّن من أربع طبقات من الداخل للخارج: المحتوى (content)، ثم الحشو (padding) وهو مسافة داخلية بين المحتوى والحدود، ثم الحدود (border)، ثم الهامش (margin) وهو مسافة خارجية بين العنصر وجيرانه.

.box {
  width: 300px;
  padding: 16px;
  border: 1px solid #ccc;
  margin: 20px auto;
}

مشكلة شائعة: عرض العنصر الفعلي يصبح 300 + حشو + حدود، فيطلع أكبر مما تريد. الحل المعتمد في أغلب المواقع أن تكتب في أول ملفك:

* { box-sizing: border-box; }

وبذلك يدخل الحشو والحدود ضمن العرض المحدد، فيصبح حساب الأبعاد بسيطاً. والقيمة margin: 0 auto مع عرض محدد تضع العنصر في منتصف الصفحة أفقياً.

3Flexbox للتخطيط

Flexbox يرتب العناصر في صف أو عمود بمرونة ويوزع المسافات تلقائياً. يكفي أن تضع display: flex على العنصر الأب:

.row {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
  flex-wrap: wrap;
}

الخاصية justify-content تتحكم بالتوزيع على المحور الرئيسي (أفقي افتراضياً): center للمنتصف، space-between لأقصى الجانبين مع مسافات متساوية بينهما. والخاصية align-items تتحكم بالمحور المقابل (عمودي)، وgap تضع مسافة بين العناصر، وflex-wrap يسمح بنزول العناصر لسطر جديد عند ضيق المساحة.

وللشبكات المتعددة الأعمدة مثل صفحة بطاقات استخدم Grid:

.cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(240px, 1fr));
  gap: 18px;
}

هذا السطر يعرض أكبر عدد ممكن من البطاقات في الصف، ويقلل الأعمدة تلقائياً على الجوال دون أي كود إضافي.

4التصميم المتجاوب

أكثر زوار المواقع اليوم يتصفحون من الجوال، لذلك يجب أن تتكيف صفحتك مع أي حجم شاشة. أول خطوة وسم viewport في head، وبدونه تُعرض الصفحة بعرض سطح المكتب مصغّراً:

<meta name="viewport" content="width=device-width, initial-scale=1">

ثانياً: استخدم وحدات مرنة بدل الثابتة. النسبة المئوية و rem و max-width أفضل من العرض الثابت بالبكسل. ولجعل الصور لا تتجاوز حاويتها:

img { max-width: 100%; height: auto; }

ثالثاً: استعلامات الوسائط (Media Queries) لتغيير التنسيق عند عرض معين:

.sidebar { width: 30%; }
@media (max-width: 700px) {
  .sidebar { width: 100%; }
}

نصيحة: صمّم أولاً للجوال ثم وسّع للشاشات الأكبر، فهذا غالباً أبسط. واختبر الموقع بأدوات المطور في المتصفح (F12 ثم أيقونة الجوال) قبل نشره.
